# Security Policy

## Supported Versions

Security updates are currently provided for the latest public release of this project.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately instead of opening a public GitHub issue.

You can contact the maintainer at:

**Email:** mhmdwaelanwr@gmail.com

Please include the following information when possible:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected app version or release
- Any relevant screenshots, logs, or proof of concept
- Your recommended fix, if available

## Sensitive Data and Secrets

Do not commit sensitive credentials to this repository, including:

- API keys
- Access tokens
- Private keys
- Hedera account private keys
- Firebase or service credentials
- Database passwords
- `.env` or local configuration values

Local secrets should be stored outside version control, such as in `local.properties`, environment variables, or another secure local configuration method.

## Blockchain Usage Notice

This project uses blockchain technology only for educational and technical demonstration purposes, specifically for event attendance verification and tamper-resistant tracking.

This project does not provide cryptocurrency trading, investment services, token issuance, wallets, exchanges, financial speculation, or any crypto-asset promotion.
